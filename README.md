# عطارة
برنامج كاشير وإدارة مخزون يعمل محليًا بدون إنترنت.

## التخزين
- البيانات تحفظ على جهاز العميل داخل مجلد `userData` الخاص بـ Electron.
- ملف البيانات المحلي مشفّر باستخدام AES-256-GCM، ومفتاح التشفير محمي بواسطة Windows DPAPI عبر Electron `safeStorage`.
- يتم إنشاء نسخ تلقائية محلية أثناء الحفظ مع الاحتفاظ بآخر 10 نسخ.
- النسخ الاحتياطية اليدوية بصيغة JSON ويمكن نقلها إلى جهاز آخر واستعادتها.

## Windows
نسخة Electron الحالية تستهدف Windows 10 وما بعده. لدعم Windows 7/8 يلزم خفض إصدار Electron، وهو غير موصى به للتوزيع الحديث.

## بناء EXE
```bash
npm install
npm run dist
```
أو استخدم GitHub Actions من تبويب Actions لبناء ملف التثبيت.
